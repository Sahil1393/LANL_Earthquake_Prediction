// 04 · Architecture

Modular ML pipeline

01
Data Ingestion
Reads train.csv · Splits into 150K-row segments · Stores raw chunks
02
Data Transformation
Signal cleaning · Normalization & scaling · Handles large time-series
03
Feature Engineering
30+ statistical features · Spectral features · Saves feature columns .pkl
04
ML Training
XGBoost & CatBoost · Cross-validation · Saves best model.pkl
05
DL Training
Keras LSTM + Dense · Adam optimizer · Saves .keras + scaler
06
Prediction
Loads best model · Runs inference · Returns TTF in seconds
Tech Stack
Python 3.10+ NumPy Pandas Scikit-learn XGBoost CatBoost TensorFlow / Keras SciPy Pickle Flask (app.py) Logging Jupyter Notebook
